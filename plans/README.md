## Dependency notes

- Plan 001 has no dependencies. It should land before any further payroll,
  admin view-as, or student-card work, because it fixes the shared data
  consistency contract those screens rely on.
- Plan 002 is the UI foundation. It centralizes radius ownership before shell
  chrome and feature headers are touched, avoiding another round of local
  radius overrides during later plans.
- Plan 003 requires Plan 002 because the month island must consume the
  canonical nav/pill radius contract while its geometry is stabilized.
- Plan 004 requires Plan 003 because scroll-away headers need an exact top
  chrome extent; implementing them against the current approximate 58px inset
  would preserve the overlap bug.
- Plan 005 runs last. It hardens the final radius, top-island, and scroll-header
  behavior after the production migrations have landed.
- Plan 001 is independent from Plans 002-005 and is already complete.

## Findings considered and rejected

- "Rewrite all Riverpod providers into a new architecture": rejected for this
  bug. The evidenced failure is not Riverpod itself; it is inconsistent teacher
  scoping across reset, student detail providers, backend listings, and
  invalidation.
- "Fix salary formulas again": rejected for this bug. Salary can already show
  reset data while calendar/student history remain stale; that points to scope
  and refresh consistency rather than salary math.
- "Use literally one corner radius for every element": rejected. Cards,
  controls, panels, pills, circles, sheets, and painter micro-geometry have
  different structural roles; consistency requires semantic ownership, not
  flattening every shape to one number.
- "Pin a compact title under the transparent month island": rejected. It
  creates a second persistent top layer and recreates text/capsule collisions.
  The selected direction is one normal-flow header that scrolls and fades away.
- "Fix each screen with a local top spacer": rejected. The top island changes
  height today and local offsets would drift again; Plan 003 establishes one
  exact shell metric first.
